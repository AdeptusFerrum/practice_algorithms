# Практикум по алгоритмам

Решения 10 контрольных работ на Java.

## Структура

- `src/main/java/kt1` – `src/main/java/` — решения задач и `Main.java` для каждой КТ.
- `src/test/java/kt1` – `src/test/java/` — тесты для решений.
- `pom.xml` — настройки Maven и JUnit.

## Запуск

Откройте проект в IntelliJ IDEA через `pom.xml`. Требуется JDK 17 или новее.

Для запуска примеров откройте `Main.java` нужной контрольной работы.
Тесты можно запустить командой `mvn test`.
